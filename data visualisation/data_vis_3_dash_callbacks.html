Callback · Concept

Concept A callback is a Python function. Dash runs it when an input property changes and writes its return values into output properties.

the callback that makes the continent dropdown work
Every box is a component id plus one of its properties. Dash connects properties, never whole components.
Callback · Example: the continent dropdown

Example The decorator lists five outputs and one input. Called directly as a Python function with Asia, it returns five values.

@callback(
    Output('kpi-countries', 'children'),
    Output('kpi-pop', 'children'),
    Output('kpi-life', 'children'),
    Output('top-pop', 'figure'),
    Output('life-trend', 'figure'),
    Input('continent', 'value'))
def update(continent):
    d = df if continent == 'All' else df[df.continent == continent]
    d07 = d[d.year == 2007]
    top = d07.nlargest(5, 'pop')
    trend = d.groupby('year').lifeExp.median().reset_index()
    return (f"{d07.country.nunique()}", f"{d07['pop'].sum() / 1e9:.2f} bn",
            f"{d07.lifeExp.median():.1f}",
            px.bar(top, x='country', y='pop'),
            px.line(trend, x='year', y='lifeExp'))

Callback · Mechanism: one change, one request

Mechanism The browser holds every property. When one changes, it sends the inputs to the server, which runs the function and returns the outputs as JSON.

Callback · Drawbacks

Drawbacks Every change is a round trip to the server. Changing the continent sent 3 requests, and a text box sends one per keystroke.

Latency

The reader waits for the network and the function. A 2-second function means a 2-second dashboard.

Chatty inputs

Typing india into a dcc.Input sent 5 requests. With debounce=True it sent 0 until Enter, then 1.

The server does the work

Every reader's every change runs Python on one machine.

dcc.Input(id='search', type='text', debounce=True)   # send on Enter or leaving the box

Patterns · 2 of 5: State and a button

State: read a value without reacting to it A State is sent along with the request, but changing it does not start one. Typing 75 sent nothing; clicking Apply sent one request.

recorded from the running app
@callback(Output('applied', 'children'),
          Input('apply', 'n_clicks'),
          State('min-life', 'value'),
          prevent_initial_call=True)
def apply(n, min_life):
    d07 = df[df.year == 2007]
    return f"{(d07.lifeExp >= min_life).sum()} countries"
Use a State for a form: the reader fills several boxes, then one click runs the filter once.

Patterns · 2 of 5: which input fired

Telling two buttons apart with ctx.triggered_id With Apply and Reset both as Inputs, the function gets both click counts. ctx.triggered_id names the one that changed.

from dash import ctx

@callback(Output('applied', 'children'),
          Output('min-life', 'value'),
          Input('apply', 'n_clicks'),
          Input('reset', 'n_clicks'),
          State('min-life', 'value'),
          prevent_initial_call=True)
def apply(n_apply, n_reset, min_life):
    d07 = df[df.year == 2007]
    if ctx.triggered_id == 'reset':
        return f"{(d07.lifeExp >= 60).sum()} countries", 60
    return f"{(d07.lifeExp >= min_life).sum()} countries", min_life

Patterns · 3 of 5: chained callbacks

Chained callbacks: a dropdown that depends on another One callback writes the property another callback reads. Choosing Europe sent 2 requests, one after the other.

Patterns · 4 of 5: dcc.Store

Sharing data between callbacks with dcc.Store A Store is a property in the browser that callbacks write and read. Data put in it crosses the network twice: out to the browser and back.

recorded on page load, continent All
dcc.Store(id='filtered')

@callback(Output('filtered', 'data'), Input('continent', 'value'))
def store(continent):
    return subset(continent).to_dict('records')
Store what is expensive to recompute and small to send: an aggregate, a list of ids, a user's choices. 1,704 raw rows cost 494 KB per change.
Patterns · 5 of 5: PreventUpdate and Loading

Leaving an output alone: PreventUpdate and dcc.Loading Raising PreventUpdate returns HTTP 204 and the output keeps its last value. After the search box was cleared, the result still read 2 countries.

def search(text):
