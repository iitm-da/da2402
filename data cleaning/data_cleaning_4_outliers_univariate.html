Outliers · the word

Concept An outlier is a value far enough from the rest to suggest a different process produced it.

weight_kg in checkup.csv, 500 adults, one dot per row
The bulk sits between 40 and 110 kg. Nine rows sit outside it, and they got there in three different ways.

Hawkins, 1980

“An observation which deviates so much from the other observations as to arouse suspicions that it was generated by a different mechanism.”

Two separate jobs

Detection asks whether a value is far from the rest. Diagnosis asks why. Every method in this lecture does the first job.

Far from the rest is a measurement. A different mechanism is a claim about the world, and only the claim licenses a fix.

Outliers · types

3 types of outliers This lecture handles point outliers in one column. Lecture 5 takes the ones that only show across columns.

synthetic data · side strips pool every value in the panel

Point

One value against the whole column. Every method today is built for this case.

Contextual

The value is ordinary for the column and wrong for its time, place or group. A detector has to be told the context.

Collective

A run of ordinary values that should not repeat. Found by looking at sequences, not single values.

A fourth kind, the joint outlier, is ordinary in every column and odd as a combination. checkup.csv holds 5 of them, and they close this lecture.
Outliers · scope of this lecture

Point outliers in one column Every method today scores one numeric column and flags values far from the rest. Deciding why a value is far stays with you.

what a detector does, and what it leaves to you

Detected today

Point outliers: a single value far from the rest of its column. Entry errors, unit errors and real extremes all look like this.

What a detector returns

A list of rows to inspect. It measures distance, so an error and a real extreme at the same value get the same score.

Outside this lecture

Contextual and collective outliers need a time or group column. Joint outliers need two columns at once and come in Lecture 5.

Methods in order: z-score, modified z, IQR fence, Grubbs, Dixon.
z-score

Concept Measure each value's distance from the mean in standard deviations, and flag anything beyond 3.

standard normal: 0.27% of values lie beyond ±3
z = (x − x) / s flag the row when |z| > 3

Where 3 comes from

Under a normal distribution 0.27% of values fall beyond ±3 sd, about 1 in 370. A value out there is rare enough to question.

What it measures

Distance in units of the column's own spread, so a 20 kg gap and a 20 mm gap become comparable.

Some texts use 2.5 or 2. The cutoff is a choice about how many clean rows you are willing to inspect.

z-score

Drawbacks The method hides the outliers it most needs to find, and in small samples it cannot flag anything.

the largest |z| any sample of size n can produce
Take nine zeros and one value of a million. The mean is 100,000 and the sd is about 316,000, so the million gets z = 900,000 / 316,000 = 2.85.

Masking

Large outliers inflate the sd and hide moderate ones. On weight, 4 of 7 errors go unflagged.

A ceiling on z: Samuelson's inequality (1968)

Put the suspect at a and the other n − 1 values at 0.

mean = a / n distance = a − a/n = a(n − 1) / n s² = [a²(n − 1)²/n² + (n − 1)a²/n²] / (n − 1) = a²/n z = [a(n − 1)/n] / [a/√n] = (n − 1)/√n

The a cancels. Equal other values is the worst case, so no sample of size n goes higher.

A fixed cutoff for any n

Clean normal data of size 486 has a 73% chance of producing at least one |z| > 3. The cutoff ignores how many values were looked at.

Two fixes follow: a yardstick the outliers cannot move, and a cutoff that grows with n.
Modified z-score

Concept Swap the mean for the median and the sd for the median absolute deviation, and flag anything beyond 3.5.

the acceptance band each method draws on weight
The robust band runs from 31.1 to 111.0 kg. The mean-based band covers every weight on the axis.
MAD = median( |x − x| ) M = 0.6745 (x − x) / MAD flag the row when |M| > 3.5

What stays the same

Distance from the centre in units of spread, and a cutoff. Only the two estimates change.

The plan

Six steps build M from 11 sorted weights. Step 4 shows where 0.6745 comes from.

Modified z-score · step 4 of 6

Intuition continued 3 The MAD measures spread on a different scale from the sd. For normal data MAD = 0.6745 σ, because half a normal lies within ±0.6745 σ.

distance of a standard normal value from its centre
|x − μ| = σ |Z|, so MAD = σ · median(|Z|) median(|Z|) = c where P(|Z| ≤ c) = 0.5 ⟺ P(Z ≤ c) = 0.75 c = Φ⁻¹(0.75) = 0.6745
σ̂ = MAD / 0.6745 = 4.10 / 0.6745 = 6.08 kg
Check on the 486 clean weights: 7.20 / 0.6745 = 10.67, against an sd of 11.00.
Modified z-score · step 5 of 6

Intuition continued 4 Divide each distance by the rescaled MAD, and M reads like a z-score. The cutoff moves to 3.5, which a normal row passes 0.047% of the time.

tails beyond 3 and beyond 3.5
M = (x − x) / (MAD / 0.6745) = 0.6745 (x − x) / MAD row 474: 0.6745 × 85.4 / 4.10 = 14.05

Iglewicz and Hoaglin, 1993

They recommend 3.5. The median and MAD wobble more than the mean and sd, so a wider cutoff keeps false flags rare.

Simulated on 20,000 normal samples of 486: 0.059% of rows past 3.5 in M, 0.26% past 3 in z.

IQR fence

Concept Draw fences 1.5 interquartile ranges beyond the quartiles, and flag anything outside them. Tukey drew it as the box plot.

box plot of weight, flagged rows drawn below the box
IQR = Q3 − Q1 lower fence = Q1 − 1.5 IQR upper fence = Q3 + 1.5 IQR

Reading the box

The box holds the middle half of the rows. The whiskers stop at the last value inside the fences.

Why quartiles

A quartile ignores the values in the outer quarter entirely, so it is robust to any outlier count below 25%.

IQR fence

Mechanism On normal data the fences sit at ±2.70 sd, so they flag 0.70% of clean values, about 1 in 143.

standard normal with the IQR fences and the ±3 line
Q1, Q3 = ±0.674 σ IQR = 1.349 σ fence = 0.674 σ + 1.5 × 1.349 σ = 2.698 σ

Expected false flags grow with n

0.70% of 500 clean rows is 3.5; of 5 million it is 35,000.

Tukey chose 1.5 by hand

He wanted a rule a person could apply to a stem-and-leaf plot. 3 IQR is his “far out” fence, at ±4.72 sd.

Grubbs' test

Concept A hypothesis test for the single most extreme value: is it one too many for a normal sample of this size?

the question Grubbs asks, on weight
Row 342 at 701 kg is the most extreme. Grubbs asks how surprising the most extreme of 500 normal values would be.
H₀: the n values are one normal sample H₁: the most extreme value came from elsewhere

What is new

A p-value, and a cutoff that depends on n. The three methods before this one used a fixed line.

The plan

Six steps build the statistic from a single z-score. Each step fixes one thing the step before it got wrong.

Grubbs' test · step 1 of 6

Intuition One value against a known mean and sd is a z-test, the same kernel as Little's test in lecture 2.

the heaviest clean row against the clean mean and sd

In words

Assume we know the true mean and sd: μ = 71.03 and σ = 11.00, from the 486 clean rows. Take the heaviest clean row, 105.2 kg, and compute z = (105.2 − 71.03) / 11.00 = 3.11.

An ordinary 5% test rejects when |z| > 1.96, so this clean row gets rejected.

The problem: we did not pick a random row. We picked the largest, and the largest is always far out.

Treat μ and σ as known

Take the 486 clean rows: μ = 71.03, σ = 11.00. Pick the heaviest clean row, 105.2 kg.

z = (105.2 − 71.03) / 11.00 = 3.11
Reject at 5% when |z| > 1.96. Squared, that is z² > 3.841 on χ²(1), rung 1 of Little's ladder.
3.11 > 1.96, so the test rejects a row that is clean.
Grubbs' test · step 2 of 6

Intuition continued 1 We did not pick a row at random; we picked the largest of 486, and the largest is far out by construction.

the cutoff has to rise with the number of values searched

In words

Picking the winner out of n values is like running n tests at once. In clean normal data, the chance that the largest |z| passes 3 is 2.7% at n = 10, 24% at n = 100 and 73% at n = 486.

The fix is to split the 5% across the n tests and test at α/n. At n = 486 the cutoff becomes 3.88.

Now 3.11 < 3.88, and the clean row survives.

Searching n values and testing the winner at α behaves like running n tests. Share α across them: test at α/n.
1. share α over n: 0.05 / 486 = 0.000103 2. two tails: 0.000103 / 2 = 0.0000514 3. cutoff c: P(Z > c) = 0.0000514 c = Φ⁻¹(1 − 0.0000514) = 3.88 one test: 0.05 / 2 = 0.025 per tail → 1.96 486 tests: 0.0000514 per tail → 3.88 row z 3.11 < 3.88: not rejected
Grubbs' test · step 3 of 6

Intuition continued 2 In practice μ and σ come from the same sample, suspect included, so the suspect shrinks its own score.

row 342 measured three ways

In words

In practice you do not know μ and σ. You use x and s from the sample, and they include the suspect. That gives Grubbs' statistic, G = max |xᵢ − x| / s.

Row 342 (701 kg) shows the effect. Measured against the clean rows it is 57.3 sd out. With its own weight included, x rises to 75.31 and s to 48.01, and G drops to 13.03.

G also cannot exceed (n − 1)/√n, which is 22.32 at n = 500 (Samuelson again). So G does not follow a normal curve, and the α/n normal cutoff from step 2 is slightly wrong.

Grubbs' test · step 4 of 6

Intuition continued 3 Grubbs worked out G's distribution under H₀. The cutoff uses a t quantile at α/(2n) and respects the ceiling.

critical G against n, with the two approximations it replaces

In words

Grubbs worked out G's distribution under H₀. In the critical value, the first factor (n − 1)/√n is the ceiling. The square-root factor is a fraction below 1 that shrinks it.

At n = 500: t = 3.922, so G_crit = 3.863. Row 342 has G = 13.03, more than 3.863, so reject.

For large n this is almost the α/n cutoff from step 2 (3.891). For small n it bends down to stay under the ceiling.

G_crit = (n − 1)/√n · √( t² / (n − 2 + t²) ) t = upper α/(2n) quantile of t on n − 2 df
n = 500: t = 3.922 G_crit = 3.863 row 342: G = 13.033 > 3.863 reject
For large n the curve sits just under the α/n normal cutoff (3.891 at 500). For small n it bends down to meet the ceiling.
Grubbs' test · step 5 of 6

Intuition continued 4 Remove the rejected value and test again. On weight, 8 rounds reject and the 9th stops at a clean row.

G in each round of remove-and-retest (generalised ESD)

In words

One Grubbs test finds at most one outlier. To find more: (1) set an upper limit r on how many outliers there could be; (2) test, remove the most extreme value, and test again, for up to r rounds; (3) keep every value up to the last round that rejected.

On weight, rounds 1–3 remove the three decimal slips, and each removal shrinks s, so G goes up. Rounds 4–8 catch the four pound rows and the real 138 kg adult. The z-score missed the pound rows because it never took the slips out of s.

Round 9 reaches a clean 105.2 kg row: G = 3.07 < 3.86, so it stops. Total: 8 flagged.

Rosner's generalised ESD, 1983

Set an upper bound on the outlier count, run that many rounds, and keep every value up to the last round that rejects.

Rounds 1 to 3 take out the decimal slips. Each removal shrinks s, so G rises.
Rounds 4 to 8 reach the 4 pound rows and the 138.0 kg adult. The z-score missed the pound rows because the slips were still in s.
Round 9 tests a clean 105.2 kg row: G = 3.073 < 3.859. The loop stops.
Grubbs' test · step 6 of 6

Intuition continued 5 Two outliers side by side hide each other inside one round. Tietjen-Moore tests the pair together, with k fixed in advance.

10 titration readings, two high
Removing one of the pair first gives G = 2.462 > 2.215. Round 1 never gets there.

In words

Two outliers sitting close together shield each other: each pulls x toward itself and widens s. Here round 1 gives G = 1.883 < 2.290, so ESD stops before it starts. Removing one of the pair first would give G = 2.462, which rejects, but round 1 never gets that far.

The fix is Tietjen-Moore: test the k suspects together, with k fixed in advance. E_k = spread of the data with the k removed ÷ spread of all the data. A small E_k means removing them collapses the spread.

Here E₂ = 0.083. The 5% critical value, simulated from 100,000 normal samples of 10, is 0.231. So reject.

G = 1.883 critical 2.290 round 1 does not reject, so ESD stops

Masking inside one round

Each of the pair pulls x toward itself and doubles the spread, so neither looks far from the rest.

E_k = Σ (xᵢ − x_k)² / Σ (xᵢ − x)² sums: kept rows over all rows small E_k: removing k values collapses the spread
E₂ = 0.083. Simulated 5% critical value, 100,000 normal samples of 10: 0.231. Reject.

Grubbs' test

Assumptions 4 conditions behind the critical value.

AssumptionWhat happens when it fails
The clean values are normal G_crit is derived from the normal. Run on BLUE METAL returns, ESD rejects for 26 rounds, because the tails are heavy and every tail day looks like one too many.
An upper bound on the count ESD needs r before it starts, and Tietjen-Moore needs the exact k. Too small an r stops early; a wrong k tests the wrong hypothesis.
Values are independent Consecutive returns and repeated readings on one instrument are correlated, which shrinks s and inflates G.
n of at least 7 Below that the ceiling and the critical value nearly meet, so only an extreme value can reject.

Masking returns in small samples

Two outliers side by side beat round 1. The next test is built for small samples and has the same weakness.

Dixon's Q test

Concept For 3 to 10 readings: divide the gap between the suspect and its neighbour by the range of the sample.

the two lengths Q compares
Q = gap / range = (x₍ₙ₎ − x₍ₙ₋₁₎) / (x₍ₙ₎ − x₍₁₎) reject when Q > Q_crit(n)

Dixon, 1950

Built for analytical chemistry, where a sample runs 3 to 10 replicate readings, too few for a stable standard deviation.

Sorted values only

Just sorted values and two subtractions, so it can be done at the bench.

Dixon's Q test

Example The same seven readings, highest at 10.21. Q = 0.333 against a critical 0.568, so the reading stays.

gap 0.03 over range 0.09
Q = (10.21 − 10.18) / (10.21 − 10.12) = 0.03 / 0.09 = 0.333 < 0.568

Not rejected

Grubbs kept this reading too. On one clear suspect the two tests agree.

What capping does

The day's return becomes +4.42% instead of +31.6%. Every later level is scaled by 0.793.

Deleting the day does the same damage: the next return absorbs the jump, and a rule that deletes it removes that one too.
The action is a note in the log saying the series has a break on this date, and a model that allows for it.
