CSV · Concept

Concept A CSV file is text: one line per row, a comma between values, column names on the first line.

bm.csv, first two rows and the last
INDEX_NAME,HistoryDate,OPEN,HIGH,LOW,CLOSE Blue Metal,2004-01-01,,,,1000.0 Blue Metal,2004-01-02,,,,1016.64 ... Blue Metal,2025-12-31,11154.45,11216.05,11108.9,11167.65
Blue: the header. Amber: ten characters that a person reads as a date. Red: empty fields where OPEN, HIGH and LOW were missing.

Stored

Characters, separated by commas and newlines. 247,290 bytes for BLUE METAL.

Left out

Column types, a marker for missing values, and the character encoding.

Whatever the file leaves out, read_csv has to guess.

CSV · Mechanism: how read_csv picks a type

Mechanism read_csv tries integer, then float, and keeps strings when both fail. An empty field is NaN, and NaN only fits in a float.

Concept JSON stores each record as name: value pairs, and a value can itself be a list or another record.

Arrow · Concept

Concept Arrow is a column layout for data in memory. Parquet is a column layout on disk, and Feather writes Arrow memory to disk as it is.

Parquet

On disk. Encoded and compressed to be small. Has to be decoded into memory before use.

Arrow

In memory. Each column is one block of values, ready for computation. pyarrow is its Python library.

Feather

On disk. The Arrow blocks written out with light compression, so reading is close to a copy.

pandas uses pyarrow to read Parquet, so every read_parquet in this lecture passed through Arrow on its way into a data frame.

Arrow · Mechanism: three layouts for a text column

Mechanism pandas object columns hold a pointer to a separate Python string for each row. Category and Arrow keep the text in one place.

how North, South, North is held in memory
A category column is dictionary encoding again, the same idea Parquet uses on disk. Arrow strings store the characters back to back and a 4-byte offset where each one starts.

Text formats

CSV and JSON can be read by a person and by every tool. They pay for it in size, speed and lost types.

Column formats

Parquet and Feather keep the schema in the file and read single columns. They need pyarrow.
